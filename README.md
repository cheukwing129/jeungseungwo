# 廉頗藺相如列傳

**線上遊玩：[https://jeungseungwo.pages.dev/](https://jeungseungwo.pages.dev/)**

由原橙光工程重製的獨立靜態網頁遊戲，包含「完璧歸趙」、「澠池之會」及
「將相和」三章。沿用原版人物、背景及音樂，並按課文核對文本與選項。
遊戲已部署於 Cloudflare Pages，遊玩時不需要橙光服務或另外安裝程式。

- 儲存庫：[cheukwing129/jeungseungwo](https://github.com/cheukwing129/jeungseungwo)
- 最近更新：2026-10-04
- 文本版本：`20261004-story-logic`
- 遊戲介面版本：`20261003-cache-audio`；載入檔案使用自動內容指紋

## 遊玩操作

首頁按「開始遊戲」，或接續同一瀏覽器內的進度。

| 操作 | 方法 |
| --- | --- |
| 閱讀下一段 | 點擊場景、對話框或「繼續」，也可按空白鍵；文字未顯示完時，先顯示整段 |
| 五倍速快讀 | 以滑鼠或觸控按住場景、對話框或「繼續」，或長按空白鍵約 0.3 秒；放開停止 |
| 回答選項 | 點擊場景中央的選項，或按對應數字鍵；提示只列目前存在的選項 |
| 自動播放 | 按「自動」切換；遇到選項即暫停，等待作答 |
| 存讀檔 | 使用三個手動存檔欄位，另有自動存檔 |
| 回看對白 | 開啟劇情紀錄；紀錄內的文字可以選取及複製 |
| 音樂與畫面 | 可切換音樂及全螢幕；全螢幕支援視瀏覽器而定 |
| 通關後重玩 | 在通關畫面或首頁開啟「章節選擇」或「路線圖鑑」 |

五倍速快讀在文字顯示完後立即接到下一段，下一頁首字立即出現，沒有額外
轉頁停頓。移動滑鼠不會中斷；遇到選項、結局、打開選單、觸控滑動頁面或
切換應用程式時會停止。若原本已開啟自動播放，放開後恢復正常速度。
鍵盤快讀遇到選項會先停止，須放開空白鍵再作答，避免按鍵重複事件誤選。
選項區是保留工具列操作的非模態問題區，可用 Tab 移到其他工具。快讀時
暫停逐頁的讀屏播報，放開後播報目前一頁；到達選項或結局時播報該內容。

音樂按鈕依播放狀態顯示「待啟動」、「載入中」、「開」、「關」、「暫停」
或「未能播放」。首頁先等待操作；開始遊戲或點擊音樂按鈕後才嘗試播放。
若瀏覽器阻擋或載入失敗，可按音樂按鈕重試。遊戲會預載已確定會播放的
下一首，切歌時重用預載元素；遇到尚未作答的分岔不預載支線。關閉音樂、
切到背景或開啟瀏覽器的節省數據模式時，停止額外預載。預載是瀏覽器提示，
實際下載量及切歌等候時間仍受網絡和瀏覽器策略影響。

## 分支與存檔

| 項目 | 目前數量 |
| --- | ---: |
| 可見對白頁 | 529 |
| 選擇點／選項 | 14／32 |
| 未通關路線 | 18 |
| 通關結局 | 1 |
| 置中間場頁 | 26 |

未通關路線在結束時提供原文提示，並可返回上一題重新抉擇。偏離原文的
支線標示為「假設情節」，另有一條理解回饋路線。唯一通關結局以將相和、
刎頸之交收束；通關後解鎖「章節選擇」及「路線圖鑑」，也可回到首頁。

自動存檔會保留結束狀態：遊戲途中首頁顯示「接續上次進度」，未通關後
顯示「返回上次抉擇」，通關後顯示「查看通關結局」。舊版存檔可繼續使用，
讀取時會更新為目前的姓名、對白、題目及結局文字。

一般對白約每兩秒儲存最新進度，減少五倍速時建立完整存檔的次數。選項、
作答後、章節切換、結局，以及開啟選單或回首頁時立即保存；切換到背景及
離開頁面時也會補存。若瀏覽器突然崩潰或被系統強制關閉，可能遺失最後
約兩秒內的普通對白進度。

自動存檔、三個手動欄位、音樂設定、通關標記及各條路線紀錄分開寫入。
同一網站的其他分頁會同步存檔清單、設定及解鎖狀態，保留各自正在閱讀的
劇情。同時遊玩的分頁仍共用一個自動存檔；同一手動欄位被刻意覆寫時，
也以最後一次儲存為準。不同欄位與不同路線的探索紀錄不會互相蓋掉。
舊版整份存檔作為兼容讀取來源，升級不會批量重寫既有手動欄位。

### 通關後重玩

- 「章節選擇」可從完璧歸趙、澠池之會或負荊請罪的開頭重玩，並接續
  後續章節；章節入口保留原劇情應有的背景、人物、音樂及變數。
- 「路線圖鑑」按章節整理全部 19 條終止路線，顯示探索進度。已探索
  路線可展開結局、原文回饋與本章抉擇順序，也可返回最後一次抉擇重玩；
  未探索路線只顯示「尚未探索」，不揭示選項或結局。
- 通關紀錄及已探索路線獨立於目前進度保存。重玩或重新開始會更新
  自動存檔，保留三個手動存檔和圖鑑，不會重新鎖上已解鎖的入口。
- 升級時若自動或手動存檔中已有通關結局，會自動解鎖；舊版停在
  「全劇終」的完成頁也能識別，不必重新通關。

進度保存在目前瀏覽器的網站資料中，不會跨裝置或瀏覽器同步；清除網站
資料會一併刪除進度、通關紀錄及圖鑑。

## 本機執行

下載或 clone 專案後，在儲存庫根目錄執行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

用瀏覽器開啟 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。請使用 HTTP
伺服器；直接雙擊 `index.html` 可能因瀏覽器的本機檔案限制而無法讀取劇情。
儲存庫已包含建置成品，直接遊玩毋須安裝 npm 套件或執行建置；若有修改，
先按下一節的維護指令重新建置。

## Cloudflare Pages 部署

目前正式遊玩網址為 [https://jeungseungwo.pages.dev/](https://jeungseungwo.pages.dev/)，
使用 GitHub 儲存庫的 `main` 分支部署。

| 設定 | 值 |
| --- | --- |
| Repository | `cheukwing129/jeungseungwo` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `exit 0` |
| Build output directory | `dist` |
| Root directory | 預設的儲存庫根目錄 |

`wrangler.toml` 已指定 `pages_build_output_dir = "./dist"`。正常以 `dist/`
為發佈目錄時，入口是 `dist/index.html`；儲存庫根目錄的 `index.html`
另提供跳轉到 `dist/` 的入口，供整個儲存庫被發佈時使用。
目前保留 `exit 0`，直接發佈已提交並經 CI 核對的成品，毋須更改 Pages
控制台設定。`404.html` 令未知路徑回傳找不到頁面；本遊戲沒有深層路由。

`_headers` 只對 `build/` 與 `assets/content/` 的內容指紋檔案設定一年
immutable 快取。HTML 重新驗證；舊的平面程式／資料網址沿用一般重新
驗證行為，避免與長快取規則重疊。45 個舊素材網址透過 `_redirects`
轉向原本相同內容的指紋檔，後續更新不會把已存在的舊轉向改指新內容。

## 專案與維護

`dist/` 是可直接部署的完整成品，圖片、音樂及資料均使用本地相對路徑，
沒有橙光驗證或 Google Drive 的執行時依賴。圖片與音樂按需載入。
維護時修改 `src/`，不要直接修改生成的 `dist/`：

```sh
node tools/build.mjs
```

建置使用 Node.js 22 或更新版本，沒有外部套件。素材指紋來自實際檔案
bytes；模組及資料的網址則依最終輸出內容計算。JSON 載入以模組網址為
基準，避免移到 `build/` 後錯用頁面相對路徑。保留已發佈的內容指紋檔案，
讓尚未重載的分頁及已快取的 HTML 仍可載入原版本；請勿直接清空 `dist/`。

| 檔案 | 用途 |
| --- | --- |
| `src/index.html`、`src/styles.css` | 遊戲入口及桌面／手機版面 |
| `src/app.mjs` | 畫面、逐字顯示、劇情紀錄及存檔介面 |
| `src/engine.mjs` | 原始指令與分支播放器、舊存檔文字更新 |

| `src/autosave.mjs` | 自動存檔間隔、重要位置即存及背景補存 |

還原使用保留完整三章、最後修改於 2017-08-27 的 `data/Story.data`；
`StoryNew.data` 的第三章不完整，沒有用它覆蓋完整版本。原工程共有
2,252 個指令、530 個文本指令，修訂只略過一頁重複對白，保持全部指令
位置、分支數及跳轉位置。`sourceHash` 識別原工程，`revision` 記錄文本版本。

另檢查生成的正式入口能啟動、靜態內容符合 CSP 寫法，以及音樂被阻擋、
網絡錯誤、預載重用、過期播放回應、靜音及背景暫停的模擬情況。

`.github/workflows/game-checks.yml` 使用 Node.js 22 執行語法檢查、重新建置
並核對成品，再執行全部十組測試。無須 `package.json` 或安裝套件。修改
`src/`、`dist/`、`tools/` 或工作流程本身時會觸發，也可在 Actions 手動執行。

實際手機、桌面瀏覽器、螢幕閱讀器及慢網絡音樂仍須試玩核對；模擬測試
不代表已完成這些實測。WebMCP 預設關閉，連 `document.modelContext` 都
不讀取；如需實驗，須將 `src/config.mjs` 的 `WEBMCP_ENABLED` 改為 `true`
後重新建置。介面驗證及生命週期已有模擬測試，支援瀏覽器實測尚未完成。
