# 廉頗藺相如列傳

由使用者提供的橙光工程重製成的獨立靜態網頁遊戲。保留原版對白、
選項、劇情分支、人物及背景圖片和背景音樂。遊戲本身不呼叫橙光服務。

## 遊玩

下載或 clone 此專案後，在專案根目錄執行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

然後用瀏覽器開啟 <http://127.0.0.1:8000/>。需要使用 HTTP 伺服器，
直接雙擊 `index.html` 可能因瀏覽器的本機檔案限制而無法讀取劇情。


首頁按「開始遊戲」。點擊場景、對話框或「繼續」閱讀下一段；文字
逐字顯示時，先點一下可顯示完整段落。選項可點擊或按數字鍵 1–3。
自動播放遇到選項即停下。提供劇情紀錄、三個手動存檔及自動存檔。
按住對話框約 0.3 秒，可暫時以五倍速度顯示文字並連續換頁。文字
顯示完即接到下一段，沒有額外的轉頁停頓，下一頁首字立即出現；放開即
停止快讀，若原本已開啟自動播放則恢復正常速度。遇到選項、結局、
打開選單、滑動頁面或切換應用程式時會停止快讀。遊戲區域的點擊及
長按不再選取文字或顯示觸控反白；可在劇情紀錄中選取文字。
進度只保留於同一瀏覽器，清除網站資料或更換瀏覽器不會同步存檔。

## 還原依據

- 使用保留完整三章的 `data/Story.data`，其最後修改日期為 2017-08-27。
- `StoryNew.data` 的第三章不完整，因此沒有用它覆蓋完整舊版。
- 完整讀取 2,252 個章節指令，含 530 個文本指令、14 個選擇點、32 個選項。
- 以原始指令縮排解析巢狀分支及兩次章節跳轉。
- 保留人物原有水平位置、縮放、左右翻轉、圖片層次及透明度；立繪等比例
  貼齊場景底邊，配合移到場景下方的對話框。
- 圖片載入和淡入動畫以目前頁面的透明度為準，避免讀檔或快速換頁時
  舊的更新把正在說話的人物隱藏。
- 畫面轉換使用網頁淡入淡出，並未逐幀複製舊播放器的等候時間。
- 對話框改為場景下方，讓手機上的文字保持可讀。
- 對話框按全部 530 段對白的最長文字與原有分行預留固定高度，短句和
  逐字顯示不會改變框的大小；選項及操作列在框外。原圖兩側紋飾獨立
  放大 1.3 倍，維持比例並直向重複鋪滿兩側；文字留出相應邊距，桌面
  與手機使用各自的字級及固定尺寸。
- 三個原音效沒有出現在提供的素材中：好感度提升、琵琶、拔刀劍聲。
  對應位置使用本地合成的替代聲音；其餘原有音樂與音效沿用。

## 專案

`dist/` 是可直接放到靜態網站主機的成品。所有遊戲素材均使用本地
相對路徑，沒有橙光驗證或 Google Drive 的執行時依賴。

- `engine.mjs`：資料與畫面分離的原始指令播放器。
- `app.mjs`：畫面、音樂、逐字顯示、對話紀錄及存檔介面。
- `pictures.mjs`：人物貼底、原圖比例及圖片切換。
- `dialogue-hold.mjs`：滑鼠／觸控長按快讀、放開停止及短按操作。
- `story.json`：從原始工程抽取的章節指令，不含帳戶或個人路徑資料。
- `assets.json`：原素材名稱與本地檔案的對照。
- `tools/nrbf.py`：僅讀資料的 NRBF 解析器，不載入或執行 .NET 類別。
- `tools/export_story.py`：抽取原始指令及建立分支位置。
- `tools/test_game.mjs`：遍歷每個可達分支、檢查素材與存讀檔。
- `tools/test_pictures.mjs`：檢查各章人物貼底、讀檔與快速換頁的立繪顯示。
- `tools/test_controls.mjs`：檢查短按、長按五倍速、無等待換頁、放開停止及選項／選單中斷。

驗證：`node tools/test_game.mjs` 及 `node tools/test_pictures.mjs`。
互動驗證：`node tools/test_controls.mjs`。

已通過全部 530 段文本、14 個選擇點、32 個選項及 19 個結局路徑的
遍歷測試，存讀檔的 JSON 往返、損壞存檔與儲存失敗處理均已檢查。
所有公開檔案使用本地相對路徑，首次載入的程式、資料及封面約 353 KB；
音樂按需載入。程式語法及介面元素對應已檢查。

此執行環境未提供靜態網站的瀏覽器預覽，因此真實手機／桌面的
視覺與點擊操作仍待試玩核對。可選的 WebMCP 功能採用偵測後註冊，
其在支援瀏覽器中的實測尚未完成，不影響一般遊戲操作。

此成品使用使用者所提供的原圖和原音樂，素材來源及原有署名均保留。

## 維護

本專案存放於 [cheukwing129/jeungseungwo](https://github.com/cheukwing129/jeungseungwo)。

- `dist/`：完整遊戲、章節資料、圖片、音樂及替代音效。
- `tools/`：原始工程的資料解析與轉換工具，以及分支／存檔驗證工具。
- 測試需要 Node.js；轉換工具及上述本機 HTTP 伺服器使用 Python 3。
- 遊戲不需要安裝 npm 套件或建置，靜態主機的發佈目錄為 `dist/`。
- 原橙光二進位工程、舊播放器與其帳戶資料不屬於網頁遊戲執行檔案。

## Cloudflare Pages 部署

連接 `cheukwing129/jeungseungwo`，正式分支選擇 `main`，Framework preset
選擇 `None`，Build command 填寫 `exit 0`，Build output directory 為 `dist`。
Root directory 保持預設的儲存庫根目錄。

`wrangler.toml` 亦明確指定 `pages_build_output_dir = "./dist"`，讓 Git
部署直接使用已完成的遊戲入口 `dist/index.html`。毋須安裝 npm 套件。

儲存庫根目錄的 `index.html` 提供跳轉入口；若整個儲存庫被發佈，首頁
會轉到 `dist/`。正常以 `dist/` 為發佈目錄時，則直接顯示遊戲首頁。

遊戲網址：<https://jeungseungwo.pages.dev/>。
