# 廉頗藺相如列傳

**線上遊玩：[https://jeungseungwo.pages.dev/](https://jeungseungwo.pages.dev/)**

由原橙光工程重製的獨立靜態網頁遊戲，包含「完璧歸趙」、「澠池之會」及
「將相和」三章。沿用原版人物、背景及音樂，並按課文核對文本與選項。
遊戲已部署於 Cloudflare Pages，遊玩時不需要橙光服務或另外安裝程式。

- 儲存庫：[cheukwing129/jeungseungwo](https://github.com/cheukwing129/jeungseungwo)
- 最近更新：2026-10-03
- 文本版本：`20261003-text-flow`
- 遊戲介面版本：`20261003-replay`

## 遊玩操作

首頁按「開始遊戲」，或接續同一瀏覽器內的進度。

| 操作 | 方法 |
| --- | --- |
| 閱讀下一段 | 點擊場景、對話框或「繼續」，也可按空白鍵；文字未顯示完時，先顯示整段 |
| 五倍速快讀 | 以滑鼠或觸控按住場景、對話框或「繼續」約 0.3 秒；放開停止 |
| 回答選項 | 點擊場景中央的選項，或按對應數字鍵；提示只列目前存在的選項 |
| 自動播放 | 按「自動」切換；遇到選項即暫停，等待作答 |
| 存讀檔 | 使用三個手動存檔欄位，另有自動存檔 |
| 回看對白 | 開啟劇情紀錄；紀錄內的文字可以選取及複製 |
| 音樂與畫面 | 可切換音樂及全螢幕；全螢幕支援視瀏覽器而定 |
| 通關後重玩 | 在通關畫面或首頁開啟「章節選擇」或「路線圖鑑」 |

五倍速快讀在文字顯示完後立即接到下一段，下一頁首字立即出現，沒有額外
轉頁停頓。移動滑鼠不會中斷；遇到選項、結局、打開選單、觸控滑動頁面或
切換應用程式時會停止。若原本已開啟自動播放，放開後恢復正常速度。

## 分支與存檔

| 項目 | 目前數量 |
| --- | ---: |
| 可見對白頁 | 529 |
| 選擇點／選項 | 14／32 |
| 未通關路線 | 18 |
| 通關結局 | 1 |
| 置中間場頁 | 26 |

未通關路線在結束時提供原文提示，並可返回上一題重新抉擇。偏離原文的
支線標示為「假設情節」，另有一條理解回饋路線。唯一通關結局以將相和、
刎頸之交收束；通關後解鎖「章節選擇」及「路線圖鑑」，也可回到首頁。

自動存檔會保留結束狀態：遊戲途中首頁顯示「接續上次進度」，未通關後
顯示「返回上次抉擇」，通關後顯示「查看通關結局」。舊版存檔可繼續使用，
讀取時會更新為目前的姓名、對白、題目及結局文字。

### 通關後重玩

- 「章節選擇」可從完璧歸趙、澠池之會或負荊請罪的開頭重玩，並接續
  後續章節；章節入口保留原劇情應有的背景、人物、音樂及變數。
- 「路線圖鑑」按章節整理全部 19 條終止路線，顯示探索進度。已探索
  路線可展開結局、原文回饋與本章抉擇順序，也可返回最後一次抉擇重玩；
  未探索路線只顯示「尚未探索」，不揭示選項或結局。
- 通關紀錄及已探索路線獨立於目前進度保存。重玩或重新開始會更新
  自動存檔，保留三個手動存檔和圖鑑，不會重新鎖上已解鎖的入口。
- 升級時若自動或手動存檔中已有通關結局，會自動解鎖；舊版停在
  「全劇終」的完成頁也能識別，不必重新通關。

進度保存在目前瀏覽器的網站資料中，不會跨裝置或瀏覽器同步；清除網站
資料會一併刪除進度、通關紀錄及圖鑑。

- 遊戲區域的點擊及長按不再選取文字或顯示觸控反白；滑鼠與觸控均支援

## 本機執行

下載或 clone 專案後，在儲存庫根目錄執行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

用瀏覽器開啟 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。請使用 HTTP
伺服器；直接雙擊 `index.html` 可能因瀏覽器的本機檔案限制而無法讀取劇情。
遊戲不需要安裝 npm 套件或執行建置。

## Cloudflare Pages 部署

目前正式遊玩網址為 [https://jeungseungwo.pages.dev/](https://jeungseungwo.pages.dev/)，
使用 GitHub 儲存庫的 `main` 分支部署。

| 設定 | 值 |
| --- | --- |
| Repository | `cheukwing129/jeungseungwo` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `exit 0` |
| Build output directory | `dist` |
| Root directory | 預設的儲存庫根目錄 |

`wrangler.toml` 已指定 `pages_build_output_dir = "./dist"`。正常以 `dist/`
為發佈目錄時，入口是 `dist/index.html`；儲存庫根目錄的 `index.html`
另提供跳轉到 `dist/` 的入口，供整個儲存庫被發佈時使用。

## 專案與維護

`dist/` 是可直接部署的完整成品，圖片、音樂及資料均使用本地相對路徑，
沒有橙光驗證或 Google Drive 的執行時依賴。圖片與音樂按需載入。

| 檔案 | 用途 |
| --- | --- |
| `dist/index.html`、`dist/styles.css` | 遊戲入口及桌面／手機版面 |
| `dist/app.mjs` | 畫面、音樂、逐字顯示、劇情紀錄及存檔介面 |
| `dist/engine.mjs` | 原始指令與分支播放器、舊存檔文字更新 |
| `dist/pictures.mjs` | 立繪比例、貼底及圖片切換 |
| `dist/dialogue-hold.mjs` | 滑鼠／觸控長按快讀與短按操作 |
| `dist/storage.mjs` | 瀏覽器存檔及設定儲存 |
| `dist/replay.mjs` | 路線索引、通關紀錄、章節入口與最後抉擇的重玩位置 |
| `dist/story.json` | 完整三章指令及核對後的文本 |
| `dist/assets.json`、`dist/assets/` | 素材名稱對照及本地素材 |
| `tools/nrbf.py`、`tools/export_story.py` | 原始工程資料解析、指令抽取及分支位置建立 |
| `tools/revise_story.py`、`tools/story_edits.json` | 可重複套用的文本、選項及結尾修訂，含核對來源 |

還原使用保留完整三章、最後修改於 2017-08-27 的 `data/Story.data`；
`StoryNew.data` 的第三章不完整，沒有用它覆蓋完整版本。原工程共有
2,252 個指令、530 個文本指令，修訂只略過一頁重複對白，保持全部指令
位置、分支數及跳轉位置。`sourceHash` 識別原工程，`revision` 記錄文本版本。

原橙光二進位工程、舊播放器及帳戶資料沒有放入網頁遊戲儲存庫。
解析工具只讀取資料，不載入或執行 .NET 類別。三個缺少的原音效
「好感度提升」、「琵琶」、「拔刀劍聲」使用本地合成替代聲音；其餘沿用
提供的原圖、音樂及音效，素材來源與原有署名均保留。

課文核對來源：[教育局原文](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/ks4_08_text.pdf)、
[教育局賞析](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS4_08.pdf)。

## 驗證

測試使用 Node.js，資料轉換工具及本機 HTTP 伺服器使用 Python 3。

```sh
node tools/test_game.mjs
node tools/test_controls.mjs
node tools/test_pictures.mjs
node tools/test_revision.mjs
node tools/test_replay.mjs
```

目前自動化測試已通過全部 529 頁可見文本、14 個選擇點、32 個選項及
19 條終止路線的遍歷，以及素材、存讀檔、損壞存檔與儲存失敗處理。
另已檢查人物立繪、快速換頁、滑鼠／觸控五倍速、選項彈窗、26 段間場、
通關／重試流程及舊存檔更新。重玩測試已核對三個章節入口、全部 19 條
路線的最後抉擇、舊通關存檔解鎖、未探索路線不洩露內容，以及重新開始／
重新載入後仍保留解鎖與手動存檔。

實際手機與桌面瀏覽器的畫面及操作仍須試玩核對。可選的 WebMCP 功能
只在偵測到支援時註冊；支援瀏覽器的實測尚未完成，一般遊玩不依賴此功能。
